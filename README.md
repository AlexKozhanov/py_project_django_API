## Начало работы
### Сборка проекта 1 Локальная
1. Клонируйте репозиторий
```sh
git clone git@github.com:AlexKozhanov/py_project_django_API.git
```
2. Установите зависимости
```sh
pip install -r requirements.txt
```
или
```sh
poetry install
```
3. Создайте файл .env из копии файла .env.sample и вставьте значения переменных своими данными
```sh
copy .env.sample .env
```
4. Не забудьте создать БД
5. Активируйте миграции
```sh
python manage.py migrate
```
6. Зарегистрируйте суперпользователя и наполните БД данными (выполнять по очереди)
python manage.py add_objects выполнить только после успешной регистрации и изменении почты на свою
```
python manage.py csu
python manage.py create_group
python manage.py add_objects
```
7. Запускайте проект
```sh
python manage.py runserver
```
8. Перейдите по ссылке
```sh
http://127.0.0.1:8000/
```
